\caption[Chatbot architecture and the components tested]{Chatbot architecture and the components tested. In the deployed system the provider agent calls knowledge-base search as a tool alongside MCP tools. In the controlled configuration retrieval runs as a fixed step before generation, and the controlled replay exercises that path.
Structured-data lookup is separate from document and FAQ retrieval. GPU is the graphics processing unit server that computes embeddings and reranks. BFF is the backend for frontend, the web app's server-side layer. Next.js and FastAPI are the web frameworks of the web app and the API. pgvector is the PostgreSQL extension for vector search. Spring AI and JPA are the Java libraries of the faculty service. EduPage is the school timetable service. LLM is a large language model.}
